v0.1.1 · updated 20 October 2026

Topologi Studio

A macOS and Windows app for drawing network topology. Built with Tauri 2 and a TypeScript front end that draws on an SVG canvas. The interface is in Norwegian Bokmål, and the built-in template recreates the sketch “Network topology – UniFi Dream Machine SE”.

The library has cards, text, pills, a table, a matrix, images and device icons. Links follow the ports. Files are saved as .topo, and you can export PNG, SVG and PDF.

v0.1.1 is unsigned. macOS requires version 11 or newer, and Gatekeeper blocks a normal double-click the first time. Windows builds exist for x64 and ARM64. The PDF export is an image, so the text cannot be selected. Orthogonal routing does not go around other elements.

v0.2.0 · updated 14 October 2026

CS2 Clips

Finds highlights in Counter-Strike 2 demos, records them through the game's own demo playback and edits the clips into a montage. It runs locally. The desktop app is Rust with egui. The website is Leptos and WebAssembly.

It finds 2K–5K, aces, clutches, noscopes, wallbangs, and smoke and flash kills, among other things. The Windows zip also includes the command-line tool. Recording needs ffmpeg.

On macOS you can view matches, analyse demos and build a montage. Recording requires CS2 on Windows and is implemented, but not tested end to end yet. Steam history is tested against a fake HTTP service, not the real API. The macOS app is ad-hoc signed, not notarised.

v0.1.0 · updated 13 October 2026

TinkerLARS

A browser app for 3D design, simple circuits and code blocks, made as a Vg3 project. Inspired by the idea behind beginner tools such as Tinkercad, but written from scratch on open libraries. Not affiliated with Autodesk. The interface is available in Norwegian and English.

3D scenes are not saved yet. Shift-click is the only way to select shapes for grouping. The circuit solver is DC only, and components are placed with dropdowns, not by dragging.

v1.0.0 · 12 October 2026

Gaming CompanionGaming Companion

An AI game assistant for Windows that reads the screen, can send keyboard and mouse input, and has skills for Elden Ring, Dune: Awakening and Rocket League. It can use an OpenAI-compatible model and MCP add-ons. Dry-run is on by default. The emergency stop is F12.

The skills are unit-tested, but not verified against the real games. The key binds are suggestions. Automatic input in online games can break the terms of service and trigger anti-cheat. The README says it is for fun, learning and offline play.
