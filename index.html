v0.1.1 · oppdatert 20. oktober 2026

Topologi Studio

Program for macOS og Windows for å tegne nettverkstopologi. Laget med Tauri 2 og en TypeScript-frontend som tegner på et SVG-lerret. Grensesnittet er på norsk bokmål, og den innebygde malen gjenskaper skissen «Nettverkstopologi – UniFi Dream Machine SE».

Biblioteket har kort, tekst, piller, tabell, matrise, bilde og enhetsikoner. Koblinger følger portene. Filer lagres som .topo, og du kan eksportere PNG, SVG og PDF.

v0.1.1 er usignert. macOS krever versjon 11 eller nyere, og Gatekeeper stopper et vanlig dobbeltklikk første gang. Windows finnes for x64 og ARM64. PDF-eksporten er et bilde, så teksten kan ikke merkes. Ortogonal ruting går ikke rundt andre elementer.

v0.2.0 · oppdatert 14. oktober 2026

CS2 Clips

Finner høydepunkter i Counter-Strike 2-demoer, tar opp via spillets egen demo-avspilling og setter klippene sammen til en montasje. Kjører lokalt. Skrivebordsappen er Rust med egui. Nettsiden er Leptos og WebAssembly.

Den finner blant annet 2K–5K, ace, clutches, noscope, wallbang, røyk- og blind-kills. Windows-zipen inneholder også kommandolinjeverktøyet. Opptak trenger ffmpeg.

På macOS kan du se kamper, analysere demoer og bygge montasje. Opptak krever CS2 på Windows og er implementert, men ikke testet ende-til-ende ennå. Steam-historikken er testet mot en etterlignet HTTP-tjeneste, ikke det ekte API-et. Appen på macOS er ad-hoc-signert, ikke notarisert.

v0.1.0 · oppdatert 13. oktober 2026

TinkerLARS

Nettleserapp for 3D-design, enkle kretser og kodeblokker, laget som Vg3-prosjekt. Inspirert av ideen bak nybegynnerverktøy som Tinkercad, men skrevet fra bunnen av på åpne biblioteker. Ikke tilknyttet Autodesk. Grensesnittet finnes på norsk og engelsk.

3D-scener lagres ikke ennå. Shift-klikk er den eneste måten å velge former for gruppering. Kretsløseren er bare DC, og komponenter plasseres med nedtrekkslister, ikke ved å dra.

v1.0.0 · 12. oktober 2026

Gaming Companion

AI-spillassistent for Windows som leser skjermen, kan sende tastatur og mus, og har ferdigheter for Elden Ring, Dune: Awakening og Rocket League. Kan bruke en OpenAI-kompatibel modell og MCP-tillegg. Dry-run er på som standard. Nødstopp er F12.

Ferdighetene er enhetstestet, men ikke verifisert mot de ekte spillene. Tastene er forslag. Automatisk input i nettspill kan bryte vilkårene og utløse anti-cheat. README-en sier at det er for moro, læring og offline spill.
